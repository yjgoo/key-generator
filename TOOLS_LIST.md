# Tools List

Below is a concise list of tools available in Key Generator and what each one does.

- **Next.js Auth Secret Generator** (Path: /next-js-auth-secret-generator): Creates secure authentication secrets for Next.js applications.
- **Secure & Strong Secret Key Generator** (Path: /secure-strong-secret-key-generator): Generates cryptographically strong secret keys with configurable length.
- **Random API Key Generator** (Path: /random-api-key-generator): Produces random API keys for application access.
- **Random Password Generator** (Path: /random-password-generator): Builds strong passwords using mixed character sets.
- **Bcrypt Hash Generator** (Path: /bcrypt-hash-generator): Generates bcrypt password hashes with configurable rounds.
- **Random JWT Secret Key Generator** (Path: /random-jwt-secret-key-generator): Creates secure secret keys for signing JWTs.
- **Random UUID Generator** (Path: /random-uuid-generator): Generates RFC 4122 compliant UUIDs.
- **Random String Generator** (Path: /random-string-generator): Produces random strings for general use.
- **Random Hex Color Generator** (Path: /random-hex-color-generator): Creates random hexadecimal color codes.
- **Random Base64 String Generator** (Path: /random-base64-string-generator): Generates random Base64-encoded strings.
- **Random Alphanumeric String Generator** (Path: /random-alphanumeric-string-generator): Produces random strings using letters and numbers only.
- **Random Numeric String Generator** (Path: /random-numeric-string-generator): Generates numeric-only random strings.
- **Random MAC Address Generator** (Path: /random-mac-address-generator): Produces random MAC addresses in standard format.
